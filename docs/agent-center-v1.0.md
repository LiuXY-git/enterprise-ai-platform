# Agent Center v1.0.0 范围与边界

当前是 Week 12 的发布候选，入口见 [v1.0 README](../agent-center/v1.0/README.md)，实际状态见 [版本清单](../agent-center/release-v1.0.0.json)。

| 能力 | 已实现范围 | 不应理解为 |
| --- | --- | --- |
| 日志 | 保存请求、工具参数、回执与最终结果，跨进程查看 | 任意任务从日志自动续跑 |
| 恢复 | 特定瞬时错误有限重试，当前有效回执模板降级 | 任意错误自动修复或写操作盲目重试 |
| 人工确认 | 内容摘要绑定、拒绝/修订/过期、重复批准保护 | 生产身份认证或真实审批平台 |
| 执行 | 批准后写本地模拟记录 | 外部消息已投递 |
| 业务测试 | 固定虚构销售查询和多阶段控制 | 任意季度分析或真实客户数据结论 |
| Prompt | 分阶段候选、实际输入记录、离线对照和可选 live | 已证明幻觉率下降或已替换所有入口 |
| Demo | 讲稿与命令已准备 | 视频已录制/人工观看验收 |

旧版会话记忆和规划器继续保留为独立实验，Memory、Planning、MCP 尚未自动组合成通用 Agent。Day 60 模拟检查点恢复与本周日志回放是不同机制。

候选验收要求 721 项测试全部通过。v0.5/v0.2/v0.1 文件与历史关联的完整性也会核对，但这不等于重新运行所有历史版本的全部测试，更不等于核查远端发布状态。

视频延期和真实 Prompt 效果待验证会随候选清单保留。后续正式定版、合并推送、标签与 Release 是独立步骤，按 [Day 84 发布流程](day84-agent-v1-release.md) 执行。
