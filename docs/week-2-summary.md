# Week 2 总结：Knowledge Hub v0.2.0

## 本周目标

建立企业知识库的文档接入基础，使系统能够上传、解析并记录文档信息。

## 已完成功能

- 支持上传 PDF 文件
- 支持上传 DOCX 文件
- 支持上传 Markdown 文件
- 提取文档文本和统计信息
- 使用 SQLite 保存文档元数据
- 使用 Docker Volume 持久化数据库和日志
- 增加空文件检查
- 增加不支持文件类型检查
- 增加文档解析异常处理
- 增加应用运行日志

## API 接口

| 请求方法 | 地址 | 作用 |
| --- | --- | --- |
| GET | `/health` | 检查服务运行状态 |
| POST | `/chat` | 发送聊天消息 |
| POST | `/upload` | 上传并解析文档 |

## 支持的文件格式

- PDF
- DOCX
- Markdown

## 数据库存储内容

当前 SQLite 数据库保存：

- 文档 ID
- 文件名
- 文件类型
- Content-Type
- 文件大小
- 解析状态
- 创建时间

## 当前限制

- 暂未保存原始文件
- 暂未保存提取出的完整文本
- 暂无文档查询和删除接口
- 暂未接入向量数据库
- 暂未实现 RAG 问答

## 下一阶段

Week 3 将开始实现 RAG 系统，包括文本切分、向量化、检索和带来源的回答。
