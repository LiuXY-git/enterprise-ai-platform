# Agent Center v0.5.0：版本范围

本版按原学习路线的 Day 77 整理 Week 11 成果，当前状态为发布候选。入口见 [v0.5 README](../agent-center/v0.5/README.md)，精确状态见 [版本清单](../agent-center/release-v0.5.0.json)。

| 能力 | 已实现或验证 | 限制 |
| --- | --- | --- |
| MCP 服务 | Day 72 官方 SDK 和标准库客户端验证本地 stdio | 固定虚构销售工具；未验证远程服务认证 |
| Agent 使用 MCP | Day 73 参数与回执校验、四个预设场景 | 单次最多一次工具调用，不接受任意目标 |
| 会话记忆 | Day 75 SQLite、独立进程恢复、更新与清除 | 固定部门语句、同一会话范围、演示用户标识 |
| 模型使用记忆 | 销售/财务模板输出与已保存部门、来源一致 | 受约束模板，不查询真实业绩 |
| Planning | Day 59 原有规划器，Day 76 概念与人工计划样例 | 只规划，不执行季度分析，不自动重规划 |
| 版本验收 | 清单哈希、历史证据、旧版本完整性、分环境测试 | 不验证 GitHub 标签、Release 或线上部署 |

Memory 负责向后续请求提供背景；Planning 形成步骤和依赖；MCP 负责工具通信。三个实验的接口和状态尚未自动连接。本版不会把历史长链路工具演示、MCP 调用和会话记忆合并描述成已完成的统一系统。

## 发布范围与冻结

v0.5 清单覆盖本周实验、历史证据、稳定说明和本版发布脚本。旧版资产由原发布检查递归核验。本次验证输出放在 `docs/evidence/day77`，不纳入自身清单以避免循环哈希；`verification.json` 记录所验收的清单哈希，输出文件另附哈希。

历史记录中的根 README、文档导航、周计划与 `.gitignore` 会随进度更新，因此不要求当前值等于每一天的旧值。另有 Day 74 的 Day 75 设计稿已由 Day 75 更新为带实现链接的历史说明。以上排除项在代码与清单中明确列出；Day 75 记录的当前设计稿仍校验。实验代码、其余稳定文档和原始证据不得借此跳过检查。

规范化规则仅为 CRLF 转 LF 后计算 SHA-256。哈希用于发现文件漂移，不提供独立数字签名或供应链真实性证明。
