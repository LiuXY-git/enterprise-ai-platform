# RAG 黄金问题集

以下问题用于测试和比较 RAG 系统效果。

## 问题 1

问题：项目支持上传哪些文档格式？

预期答案：PDF、DOCX 和 Markdown。

预期来源：README.md

## 问题 2

问题：如何使用 Docker 启动项目？

预期答案：运行 `docker compose up --build`。

预期来源：README.md

## 问题 3

问题：健康检查接口是什么？

预期答案：`GET /health`。

预期来源：README.md

## 问题 4

问题：数据库保存了哪些文档信息？

预期答案：文件名、文件类型、Content-Type、大小、状态和创建时间。

预期来源：docs/database.md
