# Agent Center v0.5.0

Week 11（Day 71–77）阶段候选版本。本文件可作为后续正式 Release 说明正文；仅有该文件不表示已经发布。

## 本版包含

- 本地 stdio MCP Server，暴露虚构销售库的固定只读查询。
- Agent 发现并检查工具契约，通过 MCP 查询并回填结果，核对报告金额、范围与来源。
- 独立 Conversation Memory CLI：SQLite 会话保存、新进程恢复、部门更新、清除、重复请求处理。
- MCP、Memory、Planning 学习材料及人工季度规划样例；复用既有 Day 59 规划器。
- 版本文件清单、历史证据关联、v0.1/v0.2 完整性检查与分环境离线验收。

## 验证

发布验收要求 456 项离线测试全部通过：418 项去重回归、38 项发布检查；不得有失败、错误或跳过。

历史真实 Qwen 证据：Day 73 两个 MCP 场景共 4 次请求；Day 75 两个记忆模板场景共 2 次请求，均为虚构教学输入。Day 77 不新增模型或外部业务请求。

正式发布应附上定版后的 `verification.json`，并在发布正文写明实际定版日期、标签指向的完整提交 SHA 与该验收文件记录的 manifest SHA-256。这些值必须来自定版过程，不使用候选提交代替。

## 能力边界

本版为宿主机 CLI 与独立学习实验集合。MCP 调用、会话记忆和规划器尚未自动串联；没有任意目标执行、跨会话长期画像、Agent HTTP API、远程 MCP 认证或生产身份认证。

Memory 支持固定部门语句和不含业绩数字的日报模板；Planning 样例不执行季度分析。SQLite 任务检查点、工具调用和会话恢复各有独立范围，不能视为统一的执行恢复系统。

平台 API 版本不随组件发布改变；Day 55 视频、Workflow Center v1.0 Release、企业微信真实发送仍为独立待办。
