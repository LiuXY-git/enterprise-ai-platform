# Agent Center v1.0.0 候选说明

Week 12（Day 78–84）阶段候选，交付宿主机 CLI 学习实验与固定销售工作流。当前尚未正式定版，本文不是已发布状态的证明。

## 本版包含

- SQLite 任务日志与跨进程只读回放。
- 固定只读任务的有限重试、有效回执模板降级和失败停止。
- 绑定正文与接收对象的人工批准/拒绝、修订、过期和原子本地模拟记录。
- 15 个固定销售业务验收场景。
- 独立候选 Prompt、16 个双版本回放样例与可选真实模型对照入口。
- 可复刻 Demo 讲稿、版本清单、历史证据关联与分环境离线验收。

## 验收要求

721 项离线测试：677 项既有回归、44 项发布检查，全部通过，无失败、错误或跳过。正式发布前须在新的目录重新验收正式清单，并将对应的 `verification.json` 作为附件。

本次不新增模型请求或真实消息发送。历史模型证据来自父版本及其关联记录，不代表当前凭据连通性检查，也不代表 Day 82 新 Prompt 已经过真实效果验证。

固定虚构销售场景、本地 stdio MCP、本地审批和模拟发送；没有生产身份认证、Agent HTTP API、任意目标执行或真实通知服务。Memory、Planning 仍是独立实验，尚未与此流程自动串联。Prompt 候选未替换旧默认入口，其模型质量改善尚未测量。
