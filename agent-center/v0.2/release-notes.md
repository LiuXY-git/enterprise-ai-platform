# Agent Center v0.2.0

Week 10（Day 64–70）阶段版本：实现受约束的 SQL、知识检索和天气工具调用，支持单一销售拜访任务的多工具组合、部分结果保留和来源简报。

发布前填写：定版日期、标签指向的 main 提交、最终 verification.json 的 manifest_sha256。当前文档是发布说明草稿，不表示远端 Release 已存在。

## 本版包含

- 工具 schema、允许列表、严格参数校验、结果回填和执行预算。
- 独立虚构数据库的只读销售查询、Knowledge Hub 检索、固定 Open-Meteo 天气接口。
- SQL 驱动条件分支，支持无销售跳过后续查询、独立工具失败保留部分结果。
- 18 个复杂任务验收场景，以及保留失败记录的新会话重跑验证。
- 根据工具回执生成简报，明确来源、虚构数据和未完成项。
- 版本清单、历史证据哈希关联、v0.1 完整性与离线发布检查。

## 验证

发布门槛为 688 项离线测试全部通过，其中既有回归 648 项、发布检查 40 项，不得有失败、错误或跳过。真实 Qwen、隔离知识库和天气调用采用 Day 64–69 历史记录；Day 70 不新增外部调用。最终结果以定版提交重新执行验收得到的 verification.json 为准。

## 能力边界

当前为宿主机 CLI 与独立教学实验。销售和制度资料为虚构样例，历史天气仅代表记录当时的预报。没有统一 Agent HTTP API、真实工具链检查点恢复、自动重试、任意目标规划、MCP、跨线程记忆、业务写入、预订或通知发送。来源关联不等于业务真实性或原始模型摘要语义正确性证明。
